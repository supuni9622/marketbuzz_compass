ADMIN_MEMORY_MANAGER_UI_SPEC.md
MarketBuzz Compass — Admin Only

0) Purpose & Design Principles
Purpose
The Admin Memory Manager exists to:

control Nova’s long-term context

prevent accidental or silent changes to business logic

allow safe evolution of definitions, playbooks, and market knowledge

Design principles
Explicit approval for anything that affects interpretation

Immutable history (versions never overwritten)

Diff before approve

Clear ownership

Low-frequency use, high trust

This is not a content CMS.
It is a governance interface.

1) Access Control
Route: /admin/memory

Visible only to Cognito Group: Admin

Backend enforcement required (JWT + group)

Viewer users must never see:

memory editor

drafts

approval actions

7) Screen 5 — Create / Upload Memory
Purpose
Admin adds new contextual knowledge.

Option A — Create from scratch
Form fields:

Title

Type (definitions / apps / market / playbooks / admin)

Tags (multi-select)

Initial content (markdown editor)

Change note

Result:

Creates memory_items

Creates memory_versions v1 (draft)

Redirects to Review screen

Option B — Upload file (PDF / CSV / MD)
Upload flow:

Upload file

System extracts text (PDF → text)

Admin previews extracted content

Admin edits / cleans up

Save as draft memory item

Nova does not auto-approve uploads.

Backend mapping
POST /admin/memory/create

POST /admin/memory/upload

8) Nova Draft Awareness (Special UX)
When draft is created by Nova:

Show banner:

“This draft was generated by Nova. Please review carefully before approving.”

Show:

Which Nova output referenced this draft

Link to Monthly Brief that depends on it

This builds trust and accountability.

9) Safety Rules (UI-Enforced)
Hard rules
No editing active versions

No deleting versions

No approving own changes without comment (optional but recommended)

Definitions (metrics/lifecycle) require explicit warning on approval

Warning modal (for definitions)
“This change affects how revenue and lifecycle are interpreted.
Are you sure?”

With this Memory Manager:

Nova never silently rewrites rules

Historical explanations remain consistent

Admins stay in control

Audits are trivial

Trust compounds over time

This is the difference between an AI assistant and an institutional analyst.
